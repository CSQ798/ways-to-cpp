# Ways to cpp · C++ 项目式训练手册

十个由浅入深的小项目，把 C++ 从「会语法」带到「会做事」。

> **在线浏览**：<https://csq798.github.io/ways-to-cpp/>
> **离线版本**：[`Ways to cpp.pdf`](Ways%20to%20cpp.pdf)（72 页 A4，与网页内容完全一致）

## 这是什么

一本写给**人工智能专业大一学生**的 C++ 项目式训练手册。

你已经学完了基础知识、数据类型、运算符、输入输出、循环与分支、数组、字符串、结构、指针、函数，
但一到算法层面就无从下手——这不是你的问题，而是所有只做课后题的人都会遇到的坎。

这本手册不再重复语法，而是给出**十个完整的小项目**，让你用手里已有的零件做出真正能跑、能看、能用的东西。
每个项目都按同一套结构展开：

| 板块 | 作用 |
| --- | --- |
| 项目背景 | 这件事在真实世界里长什么样 |
| **本板块新知识点** | 每个项目开头先列出没学过的内容 |
| 任务拆解 | 切成 Lv1 / Lv2 / Lv3 三关，先自己写，卡住再看参考实现 |
| 参考实现 | 完整源码 + **真实运行结果** |
| 美在哪里 | 逐条讲解这段代码为什么这样写更优雅 |
| 常见陷阱 / 进阶挑战 | 少走弯路，以及继续往前走的方向 |

### 为人工智能专业做的取舍

- **收进来的**：标准库中真正日常的工具（`vector`、`map`、`sort`、文件流、`class` 与运算符重载），
  以及算法本身的思想（搜索、递归、概率）。它们是「做事要用的」。
- **挡在外面的**：模板元编程、移动语义与右值引用、智能指针、lambda 进阶用法、多线程、C++20 新特性。
  这些有价值，但对当前阶段投入产出比很低，Python 与 AI 的路线也用不上。
- 附录 C 给出了**每个知识点在 Python 里的对应物**对照表，以及一条从 C++ 走向 Python / PyTorch 的路线建议。

## 编译与运行

全部代码在 **C++11 / C++14** 标准下编写，任何一个现代编译器都能直接通过
（已验证：MinGW g++ 6.3，`-Wall` 零警告）。

```bash
g++ -std=c++14 -Wall p01_grade_analyzer.cpp -o p01
./p01          # Linux / macOS / Git Bash
p01.exe        # Windows cmd / PowerShell
```

> 十个程序**全部编译通过并真实运行过**，网页里「实际运行结果」一栏是程序的真实输出，不是手写的示意。

## 重新构建网页

网页由 `ways-to-cpp-source/` 下的 HTML 片段 + 真实的 C++ 源码与运行输出拼装而成，
不需要任何第三方依赖（只用 Node.js 内置模块）：

```bash
node ways-to-cpp-source/build.js index.html
```

脚本会把 `ways-to-cpp-code/` 里的源码做**灰度语法高亮**后注入页面，
并读取 `ways-to-cpp-code/_out/` 下的真实输出填充「实际运行结果」。

重新生成 PDF（Windows，需已安装 Edge）：

```bat
msedge --headless=new --no-pdf-header-footer --print-to-pdf="Ways to cpp.pdf" "index.html"
```

## 排版约定

全书严格遵循**白底黑字**：整份文档只使用黑色、白色与灰色，连代码高亮也是灰阶
（关键字加粗纯黑、类型深灰、注释浅灰斜体、终端输出黑底白字）；
字体统一使用宋体（`SimSun`），代码块亦同——SimSun 的 ASCII 是等宽半角的，缩进不会错位。

## 一点说明

手册中的项目难度是刻意控制的：**不要先看参考实现**。

那四十分钟的价值也大于直接抄一遍。
